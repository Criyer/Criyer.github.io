# Criyer.github.io — Portfolio de Cristian Blanco

Portfolio personal desarrollado para la actividad del **Tema 06 (Diseño de Interfaces Web)**, alojado en **GitHub Pages** (`https://Criyer.github.io/`).

## Estructura del proyecto

- `index.html`: Página principal con secciones de Inicio, Sobre mí, Proyectos (3 del ciclo + 1 nuevo proyecto web), Habilidades y Contacto.
- `diseno.html`: Documento de diseño con planteamiento, arquitectura visual, elección de Bootstrap 5, análisis de 3 portfolios reales, diferenciación y uso de IA.
- `404.html`: Página personalizada para rutas no encontradas.
- `css/estilos.css`: Tema propio sobre Bootstrap 5 con variables CSS, tipografía fluida (`clamp()`) y soporte de modo claro/oscuro.
- `js/main.js`: Gestión del tema claro/oscuro (`localStorage`), cierre del menú móvil y validación del formulario de contacto.
- `img/`: Favicon, previsualizaciones de proyectos e imagen Open Graph.
- `cv/`: Carpeta preparada para el CV en PDF.
- `capturas/`: Capturas de pantalla en `360px` (`movil.png`), `768px` (`tableta.png`), `1280px` (`ordenador.png`) y perfil de GitHub (`perfil-github.png`).
